### 🎮 Огляд проекту
Це веб-гра-стратегія "Твій Хід" (MindStep). Мета — утримувати спільну фішку на дошці.
- **Стек:** SvelteKit 5, TypeScript.
- **Режими:** Гравець проти ШІ, Локальний (2 гравці), Онлайн.
- **Особливість:** Гнучкий інтерфейс (drag-and-drop елементів).

### 🏗️ Архітектура та Бізнес-логіка (MindStep Specifics)
Ці правила мають пріоритет над загальними інструкціями:

1.  **Headless Controllers:** Складна логіка UI (Лобі, Онлайн, Налаштування) винесена в класи-контролери у папці `src/lib/controllers/`.
2.  **Game Engine Separation:**
    * Візуалізація (`game-board`) **ніколи** не повинна впливати на логіку гри (`GameEngine`).
    * Компонент `center-info` лише відображає стан, а не змінює його.
3.  **Atomic Updates:** Оновлення стану гри має бути атомарним. Очищення вибору гравця має відбуватися на початку ходу, а не в кінці попереднього.
4.  **Standard Modal:** Усі модальні вікна використовувати через компонент `BaseModal` (стиль glassmorphism). Використовуй Snippets для наповнення контенту.

### 🐞 Специфічні інструменти діагностики
У цьому проекті налаштовано кастомний сервіс логування.

- **LogService:** Замість `console.log` використовуй `src/lib/services/logService.ts`.
- **Фільтрація шуму:**
    - Для дебагу **редагуй об'єкт `logConfig`** всередині `logService.ts`.
    - Змінюй прапорці (наприклад, `score: true`, `ai: false`), щоб бачити лише те, що треба.
    - **Важливо:** Після виправлення багу поверни `logConfig` у початковий стан.

### 🚀 Збірка та запуск

**Development:**
Не запускай `npm run dev` самостійно (це заблокує твій термінал). Попросіть користувача виконати:
```bash
npm run dev

```
Сервер буде доступний за адресою: `http://localhost:5173`

**Testing:**
Для запуску тестів використовуй економний режим:

```bash
npx playwright test --reporter=line

```
