# 🧩 Base UI Components

Ця папка містить набір універсальних, "тупих" (stateless) компонентів, які використовуються у всьому додатку MindStep.

## Принципи проектування
- **Atomic Design:** Компоненти є атомами або молекулами.
- **Svelte 5 Standards:** Використовують `$props()` та `{#snippet}` замість застарілих слотів.
- **Zero Side Effects:** Компоненти не мають знати про стори чи сервіси. Усі дані надходять через пропси, події — через колбеки.

## Основні компоненти

### [StyledButton.svelte](./StyledButton.svelte)
Універсальна кнопка з підтримкою варіантів та іконок.
- **Пропси:** `variant`, `size`, `shape`, `disabled`, `tooltip`.
- **Сніпети:** `icon` (зліва), `children` (текст).
- **Події:** `onclick`, `onmouseenter` тощо прокидаються як пропси.

### [BaseModal.svelte](./BaseModal.svelte)
Базова обгортка для модальних вікон з Glassmorphism ефектом та управлінням фокусом.
- **Пропси:** `isOpen` ($bindable), `title`, `onclose`.
- **Сніпети:** `children` (контент модалки).
- **Особливості:** Автоматично використовує `trapFocus` для доступності (A11y).

### [Toast.svelte](./Toast.svelte)
Компонент для відображення сповіщень.
- **Пропси:** `type` (info, success, error), `message`.

## Як додавати нові компоненти
1. Створіть `.svelte` файл у цій папці.
2. Визначте інтерфейс `Props` згідно з угодами Svelte 5.
3. Додайте опис у цей README.
