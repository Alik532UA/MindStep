# 🌐 Online Game Components

Компоненти для забезпечення мережевої гри через Firebase.

## Структура папки
- **/lobby:** Компоненти для передігрового стану (список гравців, налаштування кімнати).
- **/chat:** Віджети для обміну повідомленнями в реальному часі.
- **Lobby.svelte:** Основний контейнер для лобі, що з'єднує UI з `LobbyController`.
- **RoomList.svelte:** Відображення списку доступних публічних кімнат.

## Архітектурний паттерн
Усі складні компоненти в цій папці працюють за принципом **Headless Controller**:
1. Компонент ініціалізує відповідний контролер (наприклад, `LobbyController`).
2. Дані для відображення беруться безпосередньо з реактивних полів контролера.
3. Дії користувача викликають методи контролера.

## Основні компоненти

### [Lobby.svelte](./Lobby.svelte)
Головний компонент лобі гри.
- **Пропси:** `roomId`.
- **Контролер:** `LobbyController.svelte.ts`.

### [RoomCard.svelte](./RoomCard.svelte)
Картка кімнати в списку.
- **Пропси:** `room` (об'єкт RoomSummary).
- **Дії:** `join` (виклик `roomService.joinRoom`).

## Правила розробки
- Не пишіть логіку Firestore прямо у компонентах. Використовуйте `roomService.ts`.
- Використовуйте `BaseModal` для всіх діалогових вікон створення кімнат.
