# Аналіз файлів у папці `static/`

Цей документ містить інформацію про те, які файли з папки `static/` використовуються в проекті, а які є застарілими або зайвими.

| Файл / Папка | Де використовується | Примітки |
| :--- | :--- | :--- |
| `404.html` | Хостинг (GitHub Pages/Firebase) | Стандартна сторінка помилки 404. |
| `dont-push-the-horses.weba` | `src/lib/services/audioService.ts` | Фонова музика гри. |
| `favicon-16px.ico` | `src/app.html` | Іконка вкладки браузера (16x16). |
| `favicon-32px.ico` | `src/app.html` | Іконка вкладки браузера (32x32). |
| `favicon-48px.ico` | `src/app.html` | Іконка вкладки браузера (48x48). |
| `favicon-64px.ico` | `src/app.html` | Іконка вкладки браузера (64x64). |
| `icon-180.png` | `src/app.html` | **Apple Touch Icon**. Ідеальний розмір для iOS. |
| `icon-192.png` | `vite.config.ts` | **PWA Icon**. Основна іконка для Android та Chrome. |

## 📁 Переміщено до `static/delete_old_files/` (Тимчасове сховище)

Ці файли були ідентифіковані як зайві та переміщені для подальшого видалення:

| Файл / Папка | Причина переміщення |
| :--- | :--- |
| `emojis/` | Проект перейшов на `lucide-svelte`. |
| `coin_1fa99.png` | Застарілий растровий файл. |
| `crown_#f98519.svg` | Дублікат / Не використовується. |
| `favicon.svg` | Тимчасово не використовується (замінено на `.ico`). |
| `logo.jpg` | Не використовується (замінено на нові PNG іконки). |
| `logo-circle.png` | Замінено на `icon-180.png`. |
| `MainMenu.png` | Старий скріншот. |

## 🔍 Технічні висновки

### 1. Перехід на Lucide Icons (Емодзі)
Проект повністю перейшов на `lucide-svelte`. Папка `static/emojis/` більше не потрібна.

### 2. Оптимізація іконок (Favicon / Apple / Android)
Тепер проект має ідеальний набір іконок для всіх платформ:
- **iOS:** Використовує `icon-180.png`.
- **Android:** Використовує `icon-192.png` та `icon-512.png` через маніфест PWA.
- **Desktop:** Використовує набір `.ico` файлів різних розмірів для максимальної чіткості вкладки.
