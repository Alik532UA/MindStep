# СТОРІНКИ З `noindex` ТУТ НЕМАЄ, і це рішення (BETA-CHECKLIST § 4.0,
# `BETA-NOINDEX-OVER-DISALLOW`).
#
# `/beta-test-checklists` донедавна стояла в кожній групі нижче — разом із
# `noindex`, який ставить сама сторінка. Разом це гірше за кожне окремо:
# `Disallow` забороняє ЗАВАНТАЖЕННЯ, тож краулер сторінку не читає й `noindex`
# у ній не бачить ніколи, а адреса, на яку хтось послався ззовні, лягає в
# індекс голим URL — прибрати його нічим, бо прибирає рівно той тег, до якого
# краулер не дійшов. У цьому профілі це найгостріше: SSR немає, і `noindex`
# виставляє клієнт ПІСЛЯ гідрації, тобто його бачить лише той краулер, який
# сторінку завантажив і відмалював.
#
# Те, що лишилося нижче, — адреси, які не віддають краулеру ВЗАГАЛІ: чернетки
# й кімнати онлайн-гри, у яких індексувати нічого й `noindex` не потрібен.
#
# Групи в robots.txt НЕ успадковуються: краулер обирає одну — найточніший
# збіг за User-agent — і виконує тільки її, ігноруючи `*` цілком. Тому кожен
# блок нижче повторює той самий перелік Disallow. Це не дублювання: рядок,
# пропущений в іменованій групі, ВІДКРИВАЄ цей шлях саме названому боту
# (SEO-v8 § 7.2). Розбіжність ловить `npm run check:build`.

User-agent: *
Disallow: /MindStep/test
Disallow: /MindStep/test-error
Disallow: /MindStep/test-main-menu-v2
Disallow: /MindStep/waiting
Disallow: /MindStep/join
Disallow: /MindStep/online/lobby/
